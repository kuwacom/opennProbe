# 公式 12 本の回帰テスト

CSE-CIC-IDS2018 の端末別 pcap 12 本(2018-02-14 の 9 本・2018-02-21 の 3 本)を変換し、出力 CSV の SHA-256 を比べる。
pcap はリポジトリに含めないので、置き場所を引数で与える。

```bash
scripts/regress.sh <2018-02-14 の pcap ディレクトリ> <2018-02-21 の pcap ディレクトリ>
```

| ファイル | 内容 |
|---|---|
| `pcaps.tsv` | 名前・大きさ・SHA-256。pcap はファイル名ではなく中身で識別する(大きさが合うファイルだけハッシュを取る) |
| `expected.sha256` | `<名前>/<モード>.csv` ごとの出力の SHA-256(`official`・`official_l7`・`nprobe`・`nprobe_l7`) |

- 変換は `--keep-truncated-tail` を付ける(末尾の途中で切れたレコードを読めた部分で使う。o14_4・o14_9 が該当)。
  期待値を作った調査用プロトタイプがそう読むため。opennProbe の既定は libpcap と同じく捨てる
- 期待値はすべて調査用プロトタイプ(Python)の出力とバイト単位で一致したもの。
  official モードは公式 CSV と 52 列全一致 0.99896・L7_PROTO 0.99984(公式と対応が取れた 415,185 組)
